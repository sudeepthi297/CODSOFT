# CodeSoft Python Programming Internship

## 📌 About the Internship

This repository contains the projects I completed as part of my **Python Programming Internship at CodeSoft**. These tasks helped me improve my Python programming skills, problem-solving abilities, and practical knowledge of application development.

## 🚀 Projects

### ✅ Task 1: To-Do List Application
A Python application designed to help users organize and manage their daily tasks.

**Features:**
- Add new tasks
- View the task list
- Update existing tasks
- Delete tasks
- Manage daily activities efficiently

### 🎮 Task 2: Rock-Paper-Scissors Game
A simple and interactive game in which the user plays against the computer.

**Features:**
- Choose Rock, Paper, or Scissors
- Generate the computer's choice randomly
- Determine the winner based on game rules
- Display the game result

### 📒 Task 3: Contact Book
A Python application for storing and managing contact information.

**Features:**
- Add new contacts
- View saved contacts
- Search contacts by name or phone number
- Update contact details
- Delete contacts
